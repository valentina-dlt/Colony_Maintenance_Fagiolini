What Comes From The Spreadsheet

The app reads the live Google Sheet on refresh and every five minutes while the page is open. Genetic line tabs, cage numbers, DOB, age, sex, genotype, notes, breeding sections, and experimental notes are interpreted from the spreadsheet. The app excludes CLS 13.

Task windows are calculated from spreadsheet DOB and line information: ear tagging, weaning, wean-info review, adult missing tags, FS pup injections, and plasma/tissue collection.

What Is Saved In This Browser

If the App Actions bridge is not configured, checked task boxes, Sheets Bridge confirmations, and Old tab SAC/Keep choices are stored only in the current browser's local storage. They are not shared across users, computers, browsers, private windows, or cleared browser profiles.

If the App Actions bridge is configured, those actions are also appended to the spreadsheet's App Actions tab and reloaded across devices on refresh.

How Sheets Bridge Works

Sheets Bridge asks: Does the app log agree with the current colony sheet? A checked-off task stays in Needs Sheet Update while the raw colony tabs still generate that task.

After the colony sheet is updated and the app no longer generates that task, it moves to Resolved In Sheet. This is the expected endpoint for completed work.

Actions That Record Or Erase Local Data

Checking a task marks it done and adds it to Sheets Bridge. Unchecking that task removes the done state and its manual confirmation state.

In Sheets Bridge, manual confirmation records that someone confirmed the Sheet update outside the automatic reconciliation flow. In Old, choosing SAC or Keep records that choice. Clear removes the Old choice. A Keep date in the past returns the mouse to review.

What Does Not Write To The Sheet

The webpage does not write into the colony source tabs. The old exact-row SAC/Keep bridge is disabled after unsafe writes were observed. The safer bridge only appends rows to App Actions, which stores who did what and when without overwriting colony data.

Basic Workflow

Start in the task views to decide what work needs to happen. All shows the full checklist, Today shows work whose window has started, and Week or Month show the same tasks on a calendar. Use filters to narrow by status, task type, line, or search text.

When you complete the real colony work, check the task box. That checkbox means the work was done in the room, not that the colony spreadsheet has already been updated. If the shared bridge is configured, the check is written to App Actions with who clicked it and when. If the shared bridge is not configured, the check is saved only in that browser.

After a task is checked, go to Sheets Bridge. If the task still appears under Needs Sheet Update, update the colony spreadsheet so the raw sheet reflects the completed work. After the next refresh, the app should stop generating that task and it should move to Resolved In Sheet.

If you click a checkbox by mistake, uncheck it. Unchecking removes the done state and clears that task's manual Sheet confirmation state. If the shared bridge is configured, the undo is also logged in App Actions so the history shows both the mistaken click and the correction.

If you are unsure whether a completed task has been reflected correctly in the colony sheet, leave it visible in Sheets Bridge until a manager or the person updating the sheet can confirm the source data.

Tasks Versus Tools

A task is a specific piece of colony work generated from spreadsheet data, such as Ear Tag, Wean, Adult Missing Tags, or Plasma/Tissue Collection. Task views are different ways to look at those generated tasks.

A tool is a workspace for a related job that is not just a single due-window checklist. Breeders reviews breeding cages and replacement options. Old reviews animals over the age cutoff. Sheets Bridge reconciles completed app tasks with the colony sheet. Instructions explains the app rules and labels.

Tool Reference

Tool Or View Type What It Is For Expected User Action
All Task view Shows the full generated task table with filters and sorting. Scan, filter, check completed tasks, and review details before doing or recording work.
Today Task view Shows open tasks whose work window has started, grouped by urgency. Use as the daily work list.
Week Task view Shows task windows or due dates across the current week. Plan near-term work and see what is coming next.
Month Task view Shows task windows or due dates across the current month. Plan colony maintenance and experiments farther ahead.
Breeders Tool Shows breeding cages as Good or Replace and lists possible replacement animals by breeding program criteria. Review breeder age status and identify candidate replacements.
Old Tool Shows animals older than P220 and tracks SAC or Keep decisions. Assign SAC, Keep with a date, or Clear an old-mouse decision.
Sheets Bridge Tool Compares checked-off app tasks with the current colony spreadsheet. Use Needs Sheet Update to know what still needs spreadsheet cleanup; use Resolved In Sheet to see tasks that disappeared after the sheet was updated.
Instructions Tool Documents where data comes from, what the app records, and how labels are calculated. Use as the team reference when a label or cutoff is unclear.
